Pattern-Maker: Euclidean Wallpaper Program

First-time users: See this introduction. to the visualization tools involved.

Mathematical background

There are 17 different ways to arrange two-dimensional patterns in the euclidean plane. These are the so-called Euclidean wallpaper groups. This program allows the user to experiment with these groups, to create patterns using a simple paint program, or to control the automatic generation of a pattern with the program.

The program is an update version of my M. S. (Mathematics) project from UNC-CH, 1983, "A Computer Implementation of the 17 Euclidean Crystallographic Groups".

User interface

The program starts up with a white graphics window. You can immediately begin to paint here by pressing the left mouse button and dragging the mouse. The controls for the color, size and transparency of the brush are located in the left panel.

There is a context menu accessible via right mouse press. The controls accessible from this menu include:

  • Change the group: to any of the 17 wallpaper groups, plus one cyclic and one dihedral group.
  • Change the plugin: there are several other plugins, besides the paint plugin:
    • texture: play with a texture applied to the fundamental region
    • affine: play with possible linear deformations of the pattern
    • dirichlet domain: drag a point around to determine different fundamental regions
  • Show a "L"-shape as contents of the fundamental region (applied on top of any other content)
  • Show the generators of the group (as symbols decorating a transparent blue copy of the default fundamental domain
  • Run/pause the automatic generation of a pattern
  • Reset: return the paint pattern to pure white.

I hope at some later date to complete the documentation for the controls shown on the left hand panel, particularly for the paint plugin, but have not the time now.
